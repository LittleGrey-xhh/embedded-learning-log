# 10.8 笔记

## 一、干了什么

1. 在嘉立创 EDA 画了一个 **7.2V → 5V 的降压电路**原理图：LDO 用 **HR1117V-5.0**，输入、输出各挂一个 **10µF/25V 电解电容**。
2. 算清这颗 LDO 的功耗与结温，定出它到底能带多少电流。
3. 查清 7.2V 输入该选什么 **Buck（开关降压）** —— 先看的 MP2122A 不行，改看 MP2315 / TPS5430。
4. 试了嘉立创 EDA 自带的仿真功能，确认它验证不了 LDO。

---

## 二、知识点

### 1. ★★★ LDO 不是降压（Buck），两者功耗模型完全不同

| | LDO（线性稳压） | Buck（开关降压） |
|---|---|---|
| 原理 | 调整管"吃"掉多余电压 | 开关管 + 电感储能斩波 |
| 多余电压去向 | **全变成热** | 基本不发热 |
| 外围器件 | 只要两个电容 | 电感 + 续流二极管 + 电容 |
| 效率 | ≈ Vout/Vin（7.2→5V 只有 69%） | 85%~95% |
| 适用 | 小电流、压差小 | 大电流、压差大 |

**判据**：名字里带 **1117** 的（HR1117、AMS1117）**全是 LDO**。压差大 + 电流大 → 必须上 Buck。

### 2. ★★★ LDO 的功耗要自己扛：P = (Vin − Vout) × Iout

本项目的 LDO 是 **HR1117V-5.0**（立创 C54560849，SOT-89，Vin ≤ 15V，5V/1A 固定输出，dropout 1.1V@1A，静态电流 2mA；引脚 VIN=3 / VOUT=2 / GND=1）。

Vin=7.2V、Vout=5V → 压差 2.2V；SOT-89 的 θJA（结到环境热阻）≈100°C/W：

| 输出电流 | 耗散功率 | 温升 |
|---|---|---|
| 100 mA | 0.22 W | +22 °C |
| 200 mA | 0.44 W | +44 °C |
| 300 mA | 0.66 W | +66 °C |
| 500 mA | 1.10 W | +110 °C → 触热关断 |
| 1 A | 2.20 W | 直接烧 |

→ **这个封装的安全区只到 200 mA 左右**，超过 300 mA 就该换 Buck。

估算套路：先算 P，再乘 θJA 得温升，加上环境温度就是结温（一般芯片 Tj(max) = 125°C）。

### 3. ★★★ 选 Buck 先看 Vin 上限，不是只看电流

- ★ **MP2122A 的 Vin 上限只有 6V**，接 7.2V 会烧 —— 电流够大也没用。
- 7.2V 输入要选耐压覆盖得住的：**MP2315（4.5–24V / 3A，SOT23-8）**、**TPS5430（5.5 – 36V / 3A）**。
- 耐压要留余量：适配器空载时电压会往上飘。

### 4. ★★ 嘉立创 EDA 的仿真验证不了 LDO

- V3.2+ 有仿真功能（Simulide + NGspice 引擎，菜单「仿真」→「仿真设置」）。
- 但**不能导入第三方 .lib / .subckt 模型**，只有自带基础元件，**没有 1117 这类 LDO 模型**，**也不算温度/热**。
- → LDO 验证只能靠**手算 P = (Vin − Vout) × Iout** + 面包板实测；真要仿真就上 LTspice。

---

## 三、踩的坑

1. **嘴上说"降压"，选型时却按 Buck 的思路走** —— 实际画的是 LDO，两种电路的功耗模型完全不同，一开始没分清。
2. **以为能用 EDA 自带仿真验证这个 LDO** —— 没有 1117 模型、也不算温度，白试一圈。
3. **选 Buck 只看电流不看耐压** —— MP2122A 差点当 7.2V 输入的方案用，其实它 Vin 上限只有 6V。
4. **网标里用了 `-` 和 `.`** —— 写成 `V-IN-7.2V`，工具容易当分隔符切；规范写法是 `VIN_7V2`。

---

## 四、遗留

1. 7.2V→5V 这路如果实际电流超 300 mA，换 Buck（MP2315 / TPS5430）重画。
2. 手算的结论还没实物验证 —— 等元件到了用面包板 + 假负载（25Ω/5W 水泥电阻）实测温升对一下。
