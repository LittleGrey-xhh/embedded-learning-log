## 关于这个仓库

- 每天的笔记在本地 `笔记/` 里写，用 `sync.sh` 同步上来
- 当月正文在 `学习日记/`，历史月份在 `归档/`
- 笔记只记「以后会忘、需要复述」的结论：原理、机制、数据、判据；排查过程不写

如果你也在学嵌入式，欢迎看 [learning-log-guide.md](learning-log-guide.md) 里的记录格式——四段结构（干了什么 / 知识点 / 踩的坑 / 遗留）坚持下来比写多少更重要。
